## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build

```bash
npm run build
npm start
```

## Features

- Fully responsive design
- Dark/Light mode toggle
- Animated scroll progress bar
- Interactive survey dashboard with charts
- 6-week expandable timeline
- Field visit map (React Leaflet)
- Image gallery with lightbox
- Search navigation
- Print-friendly layout
- SEO optimized

## Project Structure

```
app/           # Next.js App Router pages and layout
components/    # Reusable UI and section components
hooks/         # Custom React hooks
lib/           # Data, utilities, and helpers
types/         # TypeScript type definitions
public/        # Static assets
```

## Adding Your Assets

Place your project report PDF at `public/assets/csp-report.pdf` and PPT at `public/assets/csp-presentation.pptx` for download functionality.

Replace gallery images in `lib/data.ts` with your actual field visit photos.
